# Omdara — instrucciones para Claude Code

- Cuando el cliente pida un cambio, antes de hacerlo clasifícalo según
  [docs/mantenimiento.md](docs/mantenimiento.md): ¿entra en el mantenimiento
  mensual o se cotiza aparte? Dile a José la clasificación y el porqué.
- No implementes ni propongas cosas que el cliente no haya pedido en un
  requerimiento. Si para que algo funcione tienes que decidir algo que el
  requerimiento no cubre, toma la opción más simple y avísala como decisión
  tuya para que José la valide.
- Lee [README.md](README.md) y [docs/](docs/) antes de escribir documentación
  nueva.
